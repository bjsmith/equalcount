Data and code

Everything behind the report is in the GitHub repository. Summary results and inputs are committed directly. The raw ballot states and per-run measures are too large for the repository, so they are attached to the latest release as a single download.

Code

Python 3, standard library and NumPy. Each script's docstring explains how to run it.

ScriptWhat it does
model.py2023 NZ election under the proposed overhang-transfer rule.
model_2026.py2026 NZ election under the proposed overhang-transfer rule.
model_levelling.pyHow many extra list seats does full proportionality need, with and without the fix?
model_straight_ticket.pyCounterfactual: every voter gives their electorate vote to the candidate of the party they gave their party vote to ("straight-ticket").
mc_overhang.pyMonte Carlo comparison of the Current System and the Proposed System.
mc_analyse.pySummarise mc_results.csv (from `python3 mc_overhang.py run N`) into mc_summary.md.
mc_history.pyCurrent System vs Proposed System (Option 2) on actual elections, 2005–2023.
calibrate_history.pyEstimate Monte Carlo parameters from the 2005–2023 elections.
abc_history.pyApproximate Bayesian computation for the behavioural parameters, 2005–2023.
mc_calibrated.pyMonte Carlo calibrated to New Zealand elections, 2005–2023.
mc_future.pyExperiment 3: five future elections (2029–2041) from the 2026 official result.
futures_reason.pyBetween-round reasoning for Experiment 3 (mc_future.py).
mc_future_walks.pyExperiment 3 at scale: 1,000 random walks from 2026 to 2041.
mc_future_floor.pyExperiment 3 benchmark (run: python3 mc_future_floor.py 1000): on each simulated election's party votes, allocate seats by pure PR (Sainte-Laguë on parties over the threshold, no electorates) at 121 seats. This is the best any overhang fix could do on those ballots.
measures.pyShared measures for Experiments 1–3, computed from stored raw results.
analyse_measures.pySummarise runs/<experiment>/measures.csv (from measures.py) into runs/summary_measures.md.
mc_paradox.pyMonotonicity ("negative vote weight") tests for every seat rule.
run_all_measures.shRerun Experiments 1–3 storing raw ballot states, then compute every measure from them.
build_site.pyBuild the GitHub Pages site in docs/.

Reproducing the results

run_all_measures.sh reruns Experiments 1–3, stores the raw ballot states in runs/, and computes every shared measure from them. The full run takes several hours. analyse_measures.py then rebuilds the summary tables.

Election data: Electoral Commission. Seats are allocated with the Sainte-Laguë formula used in New Zealand elections. Reports and simulation outputs CC BY 4.0; code MIT.
